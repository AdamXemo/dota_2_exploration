# Cheat cards

One tiny in-game card per main hero (patch 7.41, Ancient–Divine, position-1 carry).
Mid-game, when asking an LLM for advice, load ONE card (`<key>.md`) for the hero being played instead of the long notes in `knowledge/heroes/`.
Each card is about 25 lines or under 1800 characters: Plan, Build, Pivot items, Danger, Rules.
Derived from `knowledge/heroes/*.md`, `data/curated/heroes.json`, `docs/research/03`–`05` and `knowledge/meta_snapshot.md`; where curated and data-backed counters disagree, the data wins (research 04).
Cards are hand-derived, not generated: re-check and edit them after every patch, since WR, GPM, LH/min and matchup numbers go stale.
